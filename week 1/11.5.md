# 文件入库

Git status 查看状态

Git add 文件加后缀

Git commit \-m “提交信息”提交 （必须先add

Git add \*\.文件后缀 把对应后缀名的所有文件都提交到缓存区里面

Git add \. 当前文件夹里的所有文件

Git commit 不加任何东西会进入交互界面 i进入编辑模式 esc后wq退出
